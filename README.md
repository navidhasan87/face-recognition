# face-recognition
File/Folder	Purpose
dataset/	Store pictures of people whose faces will be recognized
encodings/	Store the facial encodings generated from the dataset
attendance/	Store attendance records, e.g. CSV files
face_recognition.py	Detect faces and compare them with known faces
attendance.py	Record recognized people's attendance
camera.py	Open webcam and capture frames
main.py	Run the whole application
test_setup.py	Check whether required libraries/environment work
README.md	Explain how to install and run the project
